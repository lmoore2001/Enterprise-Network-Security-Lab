# Enterprise Network & Security Home Lab

## Overview
This repository documents my hands-on enterprise networking and cybersecurity home lab. The goal is to develop practical skills in network administration, virtualization, system administration, troubleshooting, and network security.

## Lab Objectives
- Deploy and manage a Proxmox virtualization server.
- Configure Windows Server and Active Directory.
- Practice DNS, DHCP, IP addressing, and routing.
- Implement network segmentation and firewall rules.
- Monitor network performance and security events.
- Document troubleshooting, testing, and lessons learned.

## Hardware
| Device | Intended Role |
|---|---|
| Dell OptiPlex | Proxmox virtualization server |
| Raspberry Pi 4 | Linux security testing |
| Raspberry Pi Zero W | Wireless network monitoring |
| NETGEAR Switch | Physical network connectivity |
| Laptop | Remote administration |
